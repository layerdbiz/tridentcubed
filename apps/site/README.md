# apps/site

The website, tridentcubed.com: the marketing site for Trident Cubed.

Run it from this folder with `pnpm exec vp dev --host --port 5173`, preview a
build with `pnpm exec vp build` then `pnpm exec vp preview --host --port 4173`.

Agent rules: `AGENTS.md` here and at the repository root.
